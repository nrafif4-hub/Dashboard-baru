Fitur Utama

Pipeline lengkap dari data mentah hingga rekomendasi aksi retensi donatur.

🧠
XGBoost + SMOTE
Model XGBoost dengan SMOTE oversampling dan GridSearchCV 5-fold untuk hyperparameter tuning otomatis.
📊
RFM Segmentation
Recency-Frequency-Monetary analysis otomatis dengan K-Means clustering untuk profil segmentasi donatur.
🎯
Threshold Dinamis
Recency ≥ 60 hari → churn. Bisa diubah admin via config_table.json tanpa perlu coding.
🔐
Login & Role Access
3 role (Admin, Staf Retensi, Viewer) dengan audit log setiap aksi kritis.
🔄
Auto Retrain
Scheduled retraining via cron. Model baru dibandingkan otomatis — rollback jika metrik turun.
📈
Drift Monitor
PSI (Population Stability Index) deteksi perubahan distribusi data secara otomatis.
